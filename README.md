# TaskFlow – Student Task & Deadline Manager

TaskFlow is a web-based task management application designed to help students organize their tasks, track deadlines, and monitor their progress.

## 🚀 Live Demo

https://Pannu2513.github.io/TaskFlow/

## ✨ Features

- Add new tasks with deadlines
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by All, Pending, and Completed
- Display task statistics
- Deadline status tracking
- Data saved using LocalStorage
- Responsive design for mobile devices

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Git & GitHub
- GitHub Pages
